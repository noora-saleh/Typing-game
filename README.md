# Typing Trainer

A typing speed training and testing application built using C# and Windows Forms.

##  Requirements
*   **Visual Studio 2019 or newer** (Will not build or run on older versions like 2015 or 2017).
*   .NET Framework 4.5.2 or higher.

##  Application Screens

**1. Main Screen (Form 1):**
*   Select difficulty level (Easy / Hard).
*   "About" button for application information.
*   "Exit" button to close the program.

**2. Test Screen (Form 4):**
*   Randomly shuffled words for an added challenge.
*   60-second countdown timer.
*   Displays the current word and a preview of the next word.
*   Live accuracy calculation.
*   Progress bar to track completed words.
*   "Skip" button to skip the current word (counts as a mistake).
*   Visual feedback (green/red colors) for correct/incorrect inputs.

**3. Results Screen (Form 3):**
*   Displays total time taken.
*   Shows correct and wrong word counts.
*   Displays final accuracy and level evaluation (Low / Medium / Excellent).
*   List of incorrect words typed by the user.
*   Button to return to the main screen.
